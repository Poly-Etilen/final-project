# Project Overview

## 프로젝트명

EcoSphere

---

## 프로젝트 소개

EcoSphere는 AI와 IoT를 활용하여 식물의 생육 환경을 자동으로 관리하는 스마트 식물 관리 플랫폼이다.

사용자는 Workspace를 생성하여 하나의 식물을 관리하며, AI가 추천하는 환경을 기반으로 자신만의 환경을 구성할 수 있다.

Workspace는 다른 사용자와 공유할 수 있으며, 여러 명이 함께 하나의 식물을 관리할 수 있다.

---

## 개발 목적

기존의 식물 관리 서비스는 단순히 센서 값을 보여주는 수준에 머무른다.

EcoSphere는 AI를 이용하여

- 식물별 최적 환경 추천
- 환경 진단
- 이상 상태 분석
- 주간 / 월간 리포트

를 제공하여 초보자도 쉽게 식물을 관리할 수 있도록 하는 것을 목표로 한다.
