# 기능 요구사항

## 회원

### 회원가입

- 이메일 회원가입을 지원한다.
- 이메일 인증 후 가입이 완료된다.
- 비밀번호는 BCrypt로 암호화한다.

---

### 로그인

- JWT 기반 인증을 제공한다.
- Access Token을 발급한다.
- Refresh Token은 Redis에 저장한다.

---

## 사용자

- 사용자 정보를 조회할 수 있다.
- 사용자 정보를 수정할 수 있다.
- 비밀번호를 변경할 수 있다.

---

## 재배

### 재배 생성

사용자는 새로운 버섯 재배를 생성할 수 있다.

생성 시

- 버섯 종류
- 재배 이름

을 입력한다.

---

### 환경 추천

AI에게

"OO 버섯을 키우고 싶어요."

라고 요청하면

AI는

- 온도
- 습도
- CO₂
- 조도

를 추천한다.

---

### 환경 설정

추천받은 환경을

사용자가 직접 수정 후 저장할 수 있다.

---

### 재배 종료

재배가 끝나면

- 실제 수확량
- 메모

를 저장한다.

---

## 센서

수집 항목
