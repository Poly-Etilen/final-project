# AI 기반 개인 맞춤형 버섯 재배 자동화 플랫폼

## 프로젝트 소개

본 프로젝트는 IoT 센서와 AI를 활용해 버섯 재배 환경을 자동으로 관리하고, 사용자에게
최적의 재배 환경과 생육 분석을 제공하는 개인 맞춤형 버섯 재배 플랫폼이다.

사용자는 재배하고자 하는 버섯을 선택하면 공공데이터 기반 참조 데이터를 조회해 해당
품종에 적합한 환경 범위를 추천받으며, 실시간 센서 데이터를 기반으로 Rule Engine이
자동으로 환경을 제어한다.

또한 사용자가 직접 촬영해 업로드한 생육 사진을 AI Vision 모델로 분석해 균사 성장률,
갓 크기, 색상, 병충해 여부와 함께 예상 수확 시기, 환경 개선 사항 등을 제공한다.

---

## 프로젝트 목표

- 누구나 쉽게 버섯을 재배할 수 있는 환경 제공
- IoT 기반 자동 환경 제어
- 공공데이터 기반 맞춤형 재배 환경 추천
- 실시간 환경 모니터링
- 생산성 향상을 위한 데이터 분석
- 주간 AI 리포트, 일일 피드백, 인사이트(타인의 유사 재배 사례 기반 피드백) 제공

---

## 주요 기능

### 환경 추천

사용자가 재배하려는 버섯을 선택하면 온도/습도/CO₂/조도의 최적 환경 범위를 공공데이터
기반 참조 테이블(`mushroom_reference`, Sensor Service 소유)에서 조회해 추천한다.
버섯 종류가 5가지로 고정되어 있어 AI(Vector Search/LLM) 없이 직접 조회한다.

---

### 실시간 환경 모니터링

MQTT를 통해 수집된 센서 데이터를 실시간으로 확인할 수 있다.

제공 데이터: 온도, 습도, CO₂, 조도

---

### 자동 환경 제어

Rule Engine이 센서 데이터를 분석해 가습기, 환풍기, 냉각기, 히터, LED 등의 장비를
자동 제어한다.

---

### AI 생육 분석 (Vision)

사용자가 직접 촬영해 업로드한 생육 사진을 AI Vision 모델로 분석해 균사 성장률, 갓
크기, 색상 상태, 병충해 여부, 예상 수확 시기, 환경 개선 제안을 제공한다. 카메라
센서가 자동으로 촬영하는 방식이 아니라, 사용자가 원할 때 사진을 찍어 업로드하는
방식이다.

---

### AI 주간 리포트

매주 센서 데이터를 집계해 환경 유지율, 이상 상황, 자동 제어 횟수, AI 분석 결과를
사용자에게 제공한다.
