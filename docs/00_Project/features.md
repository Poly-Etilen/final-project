# 주요 기능

## 1. AI 기반 재배 환경 추천

### 설명

사용자가 재배하고자 하는 버섯의 종류를 입력하면 AI가 임베딩된 재배 데이터를 기반으로 최적의 환경을 추천합니다.

### 제공 항목

- 온도
- 습도
- CO₂ 농도
- 조도
- 환기 주기

### 동작 과정

1. 사용자가 재배할 버섯을 선택합니다.
2. AI Service가 Embedding Service를 통해 유사한 재배 데이터를 검색합니다.
3. LLM이 최적의 재배 환경을 생성합니다.
4. 사용자는 추천된 환경을 확인하고 수정할 수 있습니다.
5. 저장 시 최종 환경 설정이 재배 정보에 저장됩니다.

### 설명

사용자는 자신만의 버섯 재배 공간을 생성하고 관리할 수 있습니다.

### 제공 기능

- 재배 생성
- 재배 조회
- 재배 수정
- 재배 삭제

### 관리 정보

- 재배 이름
- 버섯 종류
- 환경 설정
- 재배 시작일
- 재배 종료일

### 설명

IoT 센서로부터 수집된 데이터를 실시간으로 확인할 수 있습니다.

### 모니터링 항목

- 습도
- CO₂ 농도

### 제공 기능

- 실시간 환경 변화
- 환경 통계 조회

---

## 4. 자동 환경 제어

### 설명

Rule Engine이 센서 데이터를 분석하여 재배 환경을 자동으로 제어합니다.

### 자동 제어 대상

- 가습기
- 환풍기
- 냉각기
- 히터
- LED 조명

### 예시

- 습도가 기준 이하일 경우 가습기 자동 실행
- CO₂ 농도가 높을 경우 환풍기 자동 실행
- 온도가 높을 경우 냉각기 자동 실행

---

## 5. AI 생육 분석 (Vision)

### 설명

사용자가 직접 촬영하여 업로드한 생육 사진을 AI Vision 모델로 분석하여 현재 재배 상태를 판단합니다.

카메라 센서가 자동으로 촬영하는 방식이 아니라, 사용자가 앱/웹에서 사진을 찍어 업로드하는 방식입니다.

Vision 모델은 사전에 학습된 성장 단계별 이미지 패턴과 업로드된 사진을 비교하여 지표를 산출하며,
LLM은 그 지표를 해석하는 설명과 개선 방안만 생성합니다.

### 제공 정보

- 생육 점수
- 균사 성장률
- 갓 크기
- 색상 상태
- 병충해 여부
- 성장 단계
- 예상 수확 시기
- 환경 개선 제안

### 동작 과정

1. 사용자가 재배 중인 버섯 사진을 촬영하여 업로드합니다.
2. Cultivation Service가 사진을 MinIO에 저장합니다.
3. AI Service의 Vision 모델이 사진을 분석합니다.
4. LLM이 분석 결과를 해석하여 자연어 설명과 개선 방안을 생성합니다.
5. 사용자는 즉시 결과를 확인합니다.

## 6. AI 재배 리포트

### 설명

주간 및 월간 센서 데이터를 분석하여 AI가 재배 결과를 요약합니다.

### 제공 내용

- 환경 유지율
- 평균 온도
- 평균 습도
- 평균 CO₂ 농도
- 자동 제어 횟수
- 이상 환경 발생 횟수
- AI 개선 제안

---

## 7. AI 챗봇

### 설명

재배 과정에서 발생하는 궁금한 사항을 자연어로 질문하고 AI에게 답변을 받을 수 있습니다.

### 예시 질문

- 왜 성장이 느린가요?
- 언제 수확하면 좋을까요?
- 현재 환경은 적절한가요?
- 어떻게 하면 생산량을 높일 수 있을까요?

---

## 8. 재배 이력 관리

### 설명

재배가 종료되면 결과를 저장하고 이전 재배와 비교할 수 있습니다.

### 관리 정보

- 버섯 종류
- 재배 기간
- 수확량
- 재배 메모
- AI 분석 결과

### 활용

- 이전 재배 결과 비교
- 생산량 변화 분석
- 환경 개선 효과 분석

---

## 9. 실시간 알림

### 설명

환경 이상 또는 장치 이상이 발생하면 사용자에게 즉시 알림을 제공합니다.

### 알림 채널

- WebSocket
- Telegram
- Discord

### 알림 예시

- 습도가 권장 범위를 벗어났습니다.
- 환풍기가 자동으로 실행되었습니다.
- 센서 연결이 끊어졌습니다.
- AI가 환경 개선을 추천합니다.

---

## 10. 환경 데이터 시각화

### 설명

센서 데이터를 차트 형태로 시각화하여 재배 환경의 변화를 쉽게 확인할 수 있습니다.

### 제공 차트

- 시간별 온도
- 시간별 습도
- 시간별 CO₂ 농도
- 시간별 조도
- 자동 제어 이력
- 환경 유지율

---

## 11. 회원 탈퇴

### 설명

사용자는 언제든지 회원 탈퇴를 요청할 수 있습니다.

### 처리 내용

- 사용자 정보 Soft Delete
- Refresh Token 삭제
- 보유 재배 데이터 비활성화

### 특징

탈퇴 즉시 개인정보를 완전히 삭제하지 않고 Soft Delete로 처리하며,
후속 처리(토큰 삭제, 재배 비활성화)는 이벤트 기반으로 비동기 처리됩니다.
