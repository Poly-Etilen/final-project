# 주요 기능

## 1. AI 기반 재배 환경 추천

### 설명

사용자가 재배하고자 하는 버섯의 종류를 입력하면 AI가 임베딩된 재배 데이터를 기반으로 최적의 환경을 추천합니다.

### 제공 항목

- 온도
- 습도
- CO₂ 농도
- 조도
- 환기 주기

### 동작 과정

1. 사용자가 재배할 버섯을 선택합니다.
2. AI Service가 Embedding Service를 통해 유사한 재배 데이터를 검색합니다.
3. LLM이 최적의 재배 환경을 생성합니다.
4. 사용자는 추천된 환경을 확인하고 수정할 수 있습니다.
5. 저장 시 최종 환경 설정이 재배 정보에 저장됩니다.

---

## 2. 개인 재배 생성 및 관리

### 설명

사용자는 자신만의 버섯 재배 공간을 생성하고 관리할 수 있습니다.

### 제공 기능

- 재배 생성
- 재배 조회
- 재배 수정
- 재배 삭제

### 관리 정보

- 재배 이름
- 버섯 종류
- 환경 설정
- 재배 시작일
- 재배 종료일

---

## 3. 실시간 환경 모니터링

### 설명

IoT 센서로부터 수집된 데이터를 실시간으로 확인할 수 있습니다.

### 모니터링 항목

- 온도
- 습도
- CO₂ 농도
- 조도

### 제공 기능

- 현재 환경 조회
- 실시간 환경 변화
- 환경 통계 조회

---

## 4. 자동 환경 제어

### 설명

Rule Engine이 센서 데이터를 분석하여 재배 환경을 자동으로 제어합니다.

### 자동 제어 대상

- 가습기
- 환풍기
- 냉각기
- 히터
- LED 조명

### 예시

- 습도가 기준 이하일 경우 가습기 자동 실행
- CO₂ 농도가 높을 경우 환풍기 자동 실행
- 온도가 높을 경우 냉각기 자동 실행

---

## 5. AI 생육 분석

### 설명

AI가 센서 데이터를 분석하여 현재 재배 상태를 예측하고 사용자에게 제공합니다.

### 제공 정보

- 생육 점수
- 환경 유지율
- 예상 수확 시기
- 예상 품질
- 환경 개선 제안

---

## 6. AI 재배 리포트

### 설명

주간 및 월간 센서 데이터를 분석하여 AI가 재배 결과를 요약합니다.

### 제공 내용

- 환경 유지율
- 평균 온도
- 평균 습도
- 평균 CO₂ 농도
- 자동 제어 횟수
- 이상 환경 발생 횟수
- AI 개선 제안

---

## 7. AI 챗봇

### 설명

재배 과정에서 발생하는 궁금한 사항을 자연어로 질문하고 AI에게 답변을 받을 수 있습니다.

### 예시 질문

- 왜 성장이 느린가요?
- 언제 수확하면 좋을까요?
- 현재 환경은 적절한가요?
- 어떻게 하면 생산량을 높일 수 있을까요?

---

## 8. 재배 이력 관리

### 설명

재배가 종료되면 결과를 저장하고 이전 재배와 비교할 수 있습니다.

### 관리 정보

- 버섯 종류
- 재배 기간
- 수확량
- 재배 메모
- AI 분석 결과

### 활용

- 이전 재배 결과 비교
- 생산량 변화 분석
- 환경 개선 효과 분석

---

## 9. 실시간 알림

### 설명

환경 이상 또는 장치 이상이 발생하면 사용자에게 즉시 알림을 제공합니다.

### 알림 채널

- WebSocket
- Telegram
- Discord

### 알림 예시

- 습도가 권장 범위를 벗어났습니다.
- 환풍기가 자동으로 실행되었습니다.
- 센서 연결이 끊어졌습니다.
- AI가 환경 개선을 추천합니다.

---

## 10. 환경 데이터 시각화

### 설명

센서 데이터를 차트 형태로 시각화하여 재배 환경의 변화를 쉽게 확인할 수 있습니다.

### 제공 차트

- 시간별 온도
- 시간별 습도
- 시간별 CO₂ 농도
- 시간별 조도
- 자동 제어 이력
- 환경 유지율
